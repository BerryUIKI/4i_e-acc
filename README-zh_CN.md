# 4i_e-acc — 投资文档工作区

> 中文 · [English](./README.md)

本工作区用于发布与投资相关的文档。文档按下列文件夹组织，每个文件夹均包含双语 README：`README.md`（英文）与 `README-zh_CN.md`（中文）。

## 文件夹

| 文件夹 | 说明 | 英文 README | 中文 README |
|--------|------|------------|------------|
| `reports/` | 已发布的研究报告、业绩点评与分析师覆盖。 | [README.md](./reports/README.md) | [README-zh_CN.md](./reports/README-zh_CN.md) |
| `research/` | 持续研究、投资逻辑笔记与文献综述。 | [README.md](./research/README.md) | [README-zh_CN.md](./research/README-zh_CN.md) |
| `portfolio/` | 组合构建、资产配置与绩效回顾。 | [README.md](./portfolio/README.md) | [README-zh_CN.md](./portfolio/README-zh_CN.md) |
| `market/` | 宏观与市场评论、市场状态笔记。 | [README.md](./market/README.md) | [README-zh_CN.md](./market/README-zh_CN.md) |
| `strategies/` | 策略手册、回测与信号定义。 | [README.md](./strategies/README.md) | [README-zh_CN.md](./strategies/README-zh_CN.md) |
| `data/` | 数据集、参考表与外部数据来源。 | [README.md](./data/README.md) | [README-zh_CN.md](./data/README-zh_CN.md) |
| `archive/` | 已被替代或留存备查的历史文档。 | [README.md](./archive/README.md) | [README-zh_CN.md](./archive/README-zh_CN.md) |
| `assets/` | 文档引用的图表、图片与其他媒体素材。 | [README.md](./assets/README.md) | [README-zh_CN.md](./assets/README-zh_CN.md) |
| `articles/` | 长文随笔；每篇独立成夹，自带草稿、笔记与素材。 | [README.md](./articles/README.md) | [README-zh_CN.md](./articles/README-zh_CN.md) |

## 约定
- 默认文档为 `README.md`（英文），中文版本为 `README-zh_CN.md`。
- 文件夹名称使用英文；文档标题可双语。
- 使用相对路径在文档间交叉引用。
