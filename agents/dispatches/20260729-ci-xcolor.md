## The problem

CI workflow `.github/workflows/build-book-pdf.yml` fails at xelatex compilation with:

```
! Undefined control sequence.
l.18 \definecolor{dh-pink}{HTML}{FEC6CD}
! LaTeX Error: Missing \begin{document}.
```

Root cause: `\definecolor` is called on lines 18-25 of `pandoc-template.tex`, but `\usepackage{xcolor}` is loaded at line ~91. xcolor must be loaded BEFORE `\definecolor`.
