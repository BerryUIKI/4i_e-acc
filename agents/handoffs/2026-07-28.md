## 4. CI/CD — PDF 自动编译

### 架构
```
push to article/* or main
  → GitHub Actions (.github/workflows/build-book-pdf.yml)
    → apt install texlive + pandoc + fonts-noto-cjk
    → python3 build_pdf.py scan → merge → pandoc → split → xelatex × 2
    → upload PDF artifact (90天保留)
    → if main: create/update Release "book-latest"
```

### 已修复的 8 个 CI bug
1. timeout 15→90min + `--no-install-recommends`
2. `filepath.stem` → `Path(filepath).stem`
3. `mkdir -p output`（scan 前缺目录）
4. pandoc 加 `--top-level-division=chapter`
5. split 失败时 work_dir 未回退
6. `-output-directory` 与 cwd 双重嵌套
7. `run_xelatex` 重写：检查退出码 + PDF 是否存在 + 打印错误输出
8. 模板 `BoldFont={Noto Sans CJK SC Medium}` → 去掉子选项（Ubuntu 无此 weight）

### 当前 CI 状态
最后一次推送 `df2de6b`（模板字体修复）。如果 CI 仍失败，看 xelatex 输出——现在会完整打印到 log。

## 6. 常见陷阱

| 陷阱 | 说明 |
|------|------|
| 本地 git 无历史 | 用 GitHub API 推送 |
| texlive 超时 | `--no-install-recommends`，timeout ≥ 60min |
| XeLaTeX 静默失败 | `-interaction=nonstopmode` 下 exit 0 ≠ PDF 生成，必须检查文件存在 |
| CJK 字体 | Ubuntu `fonts-noto-cjk` 无 "Medium" weight |
| Pandoc chapter | 不加 `--top-level-division=chapter` 出 `\section{}` |
