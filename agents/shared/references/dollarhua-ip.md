# DollarHua IP — Agent Reference

A reusable mascot IP at `assets/dollarhua/` (character pack v1.4 Lite, designed by the repo owner). It is the single source of truth for the workspace's brand face.

## Before generating any visual

Read `assets/dollarhua/README.md` (EN) and `assets/dollarhua/README-zh_CN.md`.

## Immutable rules

| Rule | Detail |
|------|--------|
| Signature color | `#FEC6CD` (pink) — primary identity color |
| Pendant | Bronze `#B86C40` — never recolor to bright yellow gold |
| Reference PNGs | Authoritative for rendered appearance |
| No divergent copies | Always pull from `assets/dollarhua/` |
