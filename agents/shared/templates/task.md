# Task Template

Copy this for each new task. Tasks live in `agents/{main-id}/tasks/`.

A task goes through these states:
`DRAFT → READY → ASSIGNED → IN_PROGRESS → DONE → REVIEWED → MERGED`

```markdown
# TASK-NNN — {summary}

- **Status**: DRAFT
- **Window**: {window-name}
- **Sub Agent**: {sub-agent-name}
- **Locked files**: {chapter-scope or file list}
- **Created**: {date}
- **Assigned**: —
- **Completed**: —

## Description

## Input Files

## Expected Outputs

## Result Handoff
```
