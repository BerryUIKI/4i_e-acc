## 附录 L · 不同司法辖区需自行确认的事项

以下事项在不同国家和地区存在显著差异。本书不提供具体法律或税务建议，读者应当根据自己所在地的最新法规自行确认。

| 事项 | 说明 |
|------|------|
| 证券账户开立条件 | 不同国家/地区对非居民开户的限制不同 |
| 个人所得税 | 投资分红、基金赎回收益、海外投资收益的税率和申报要求因地区而异 |
| 资本利得税 | 部分地区有、部分地区没有；长期持有和短期交易的税率可能不同 |
| 预扣税（Withholding Tax） | 投资海外资产时，所在国可能对股息分红预先扣缴税款 |
| 外汇管制与额度 | 部分国家有外汇管制，限制个人每年购汇或向境外转移资金的上限 |
| QDII额度限制 | 中国境内的QDII基金受外汇管理局批准的额度限制 |
| ETF税务处理 | 不同注册地（如中国大陆、香港、美国、爱尔兰）的ETF对分红的税务处理差异 |
| 遗产税与继承 | 持有海外资产时，不同国家/地区对遗产税和继承程序的规定差异 |
| 投资者保护基金 | 不同地区对券商破产时客户资产的保护范围和上限不同 |
| 产品准入 | 部分ETF或基金因监管原因不向特定地区的居民销售 |
| 信息披露语言 | 海外ETF的招募说明书和报告语言可能是英文或其他外语 |

> **重要提醒：以上事项的具体规定以各地区最新法规为准，并可能随时更新。本书不构成法律、税务或移民建议。**

## 附录 M · 个人投资者税务自查清单

税务先分清三件事：自己的税务居民身份、所得来源地，以及产品或账户的法律结构。下面以中国大陆个人投资者的若干规则说明核对方法，查阅日期为 2026-11-05；不直接适用于其他地区，也不把暂免政策当作永久承诺。

### M1 · 一项有明确范围的股息政策

财税〔2015〕101 号针对个人从公开发行和转让市场取得的上市公司股票，规定了按持股期限差别化的股息红利政策。不能直接套到所有股权、基金分配或海外股票。

| 持股期限 | 该规则下的处理 |
|---|---|
| 1 个月以内（含） | 股息红利全额计入，适用 20% 税率 |
| 1 个月以上至 1 年（含） | 暂减按 50% 计入，适用 20% 税率，实际为 10% |
| 超过 1 年 | 股息红利暂免个人所得税 |

（来源：[财政部、税务总局、证监会财税〔2015〕101 号](https://www.chinatax.gov.cn/n810341/n810755/c1797427/content.html)；查阅日期：2026-11-05。扣缴、持股期计算及特殊证券情形应结合实际对账单与后续有效规则核对。）

### M2 · 转让差价与分配收入分开核对

通过证券账户直接持股、持有基金份额、通过互联互通机制交易，是不同情形。不要把某项买卖差价优惠扩大为“全部投资收益免税”。例如 2023 年第 23 号公告对指定的沪港通、深港通及基金互认转让差价延续暂免政策，执行至 2027-12-31；其范围不是所有海外账户、股息和利息。

来源：[财政部、税务总局、证监会 2023 年第 23 号公告](https://tianjin.chinatax.gov.cn/11200000000/0300/030004/03000418/20230823145126249.shtml)；查阅日期：2026-11-05。到期、身份或交易渠道变化时重新确认。

基金还需区分底层取得收入时的税负，与向个人分配时的处理。个人收到的分配不再扣某项税，并不意味着底层没有承受税费。财税〔2002〕128 号是有关开放式基金的基础文件之一，但具体股票、债券及跨境资产还需结合后续规则，不能把某一旧条文的税率直接当作所有基金现行总税负。

资料入口：[财税〔2002〕128 号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202818/content.html)；查阅日期：2026-11-05。

### M3 · 境外所得要同时看两地规则

先看投资地是否扣缴，再看税务居民地是否要求申报、如何抵免。某地对某类非居民资本利得不征税，不能推导出居民地没有纳税或申报义务。国籍、居住地、账户注册地和税务居民身份也不是同义词。

中国居民个人的境外所得及抵免，应核对 [个人所得税法](https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3970366/content.html) 与 [财政部、税务总局 2020 年第 3 号境外所得公告](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)。来源查阅日期：2026-11-05。购汇便利化额度也不等于证券投资准入或资金用途许可，两者需分别确认。

### N2 · 按法条核对继承安排

《民法典》第 1127 条规定的第一顺序法定继承人为配偶、子女、父母，第二顺序为兄弟姐妹、祖父母、外祖父母，具体适用还要结合其他继承规定。不要自动假定共同生活者具有同样的法定身份；有特别意愿时，应确认合法有效的安排。

遗嘱有不同法定形式与见证要求。口头遗嘱适用于危急情况；危急情况消除后，遗嘱人能够用书面或者录音录像形式立遗嘱的，原口头遗嘱无效。多份有效遗嘱内容冲突时，应依相关规则确定最后的意思表示，公证形式不再当然优先。

来源：[《中华人民共和国民法典》继承编](https://gdca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_573d6ef5018b46b6a4e1f31ca085a710.html)，重点参看第 1127、1133—1140、1142、1161 条；查阅日期：2026-11-05。清偿遗产债务等事项仍需结合实际权属与法定条件处理。

### N3 · 房产与保险不要套用绝对结论

不动产继承登记不必一律先公证，可以依当地流程使用公证文书、生效法律文书或相应继承证明材料。法定继承人通过继承承受土地、房屋权属的契税免税范围，不代表其他税费及办理成本都不存在。

来源：[浦东不动产登记问答](https://www.pudong.gov.cn/zwgk/gkml_ywl_bdcdj_bdcdjcjwd/2022/313/276079.html)、[《契税法》第六条](https://tianjin.chinatax.gov.cn/11200000000/0300/030004/03000418/p20230223141633287.shtml)；查阅日期：2026-11-05。实际材料、收费及其他减免按受理地确认。

人寿保险指定受益人后，仍要核对法定例外：例如没有指定或无法确定受益人、受益人先于被保险人死亡且无其他受益人，或丧失、放弃受益权且无其他受益人等情况下，保险金可能作为遗产。不能只写“有受益人就永不属于遗产”。

来源：[《保险法》第四十二条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_4c715a53f3d4402c89f62ae77809f638.html)；查阅日期：2026-11-05。
