## 附录 C · 风险承受能力问卷

请根据实际情况，圈选最符合自己的选项。本问卷仅供自我评估参考。

**1. 您的投资期限大约是多少年？**
A. 20年以上  B. 10-20年  C. 5-10年  D. 不到5年

**2. 您的收入稳定性如何？**
A. 非常稳定（公务员/事业编制/大型国企等）
B. 较为稳定（正规企业，有固定劳动合同）
C. 不够稳定（自由职业者/佣金制/初创企业等）
D. 极不稳定（收入来源不确定）

**3. 您的家庭现金流状况如何？**
A. 每月有稳定的正向现金流，有较多结余
B. 每月有结余但比例不高
C. 收支基本平衡，几乎没有结余
D. 每月入不敷出

**4. 如果市场下跌20%，您的第一反应是?**
A. 继续按计划定投，甚至希望抓住机会
B. 有些不安但不做出大的改变
C. 想要卖出止损
D. 会立刻清仓

**5. 您目前持有的投资资产占您可投资资产的比例大约为?**
A. >70%  B. 40-70%  C. 10-40%  D. <10%

**6. 您是否曾因为市场波动而卖出过投资资产？**
A. 从来没有
B. 偶尔有过，但后来恢复了投资
C. 经常因为害怕亏损而卖出
D. 每次都受到波动的影响做出操作

**7. 您有多少个月的生活支出以现金或现金等价物存放（不含投资账户）？**
A. 超过12个月  B. 6-12个月  C. 3-6个月  D. 不到3个月

**8. 您目前是否有高息负债（年利率>10%）？**
A. 完全没有  B. 有小额，正在还  C. 有较大金额  D. 有，且在持续增加

**9. 您能接受投资组合在一年内的最大临时损失幅度为：**
A. >30%  B. 20-30%  C. 10-20%  D. <10%

**10. 您是否有家庭成员依赖于您的主要收入？**
A. 没有（单身，无抚养人和需要赡养的人）
B. 有一个  C. 有两个或更多  D. 整个家庭完全依赖我的收入

## 附录 K · 常见金融术语表

| 中文 | English | 简要解释 |
|------|---------|---------|
| 资产 | Asset | 能够持续创造价值、带来未来经济收益的东西 |
| 负债 | Liability | 欠别人的钱，需要未来偿还 |
| 净资产 | Net Worth | 资产减去负债 |
| 流动资产 | Liquid Asset | 可以快速变现且不大幅折价的资产 |
| 通货膨胀 | Inflation | 物价普遍上涨导致货币购买力下降 |
| 复利 | Compounding | 收益也参与产生下一期收益 |
| 单利 | Simple Interest | 只对本金计算收益 |
| 72法则 | Rule of 72 | 72÷年化收益率≈本金翻倍年数 |
| 名义收益率 | Nominal Return | 未经通胀调整的收益率 |
| 实际收益率 | Real Return | 扣除通胀后的收益率 |
| 波动 | Volatility | 资产价格上下起伏的幅度 |
| 永久损失 | Permanent Loss of Capital | 资产基本面恶化导致的不可恢复损失 |
| 股息 | Dividend | 企业分配给股东的利润 |
| 市盈率 | Price-to-Earnings Ratio (P/E) | 每股价格÷每股盈利 |
| 债券 | Bond | 借钱给政府或企业，对方按期付息并到期还本 |
| 票面利率 | Coupon Rate | 债券发行时约定的年利息比率 |
| 到期收益率 | Yield to Maturity (YTM) | 持有债券至到期日的年化总回报 |
| 久期 | Duration | 债券价格对利率变化的敏感度指标 |
| 信用利差 | Credit Spread | 企业债收益率高出同期限国债的部分 |
| ETF | Exchange-Traded Fund | 在交易所交易的指数基金 |
| 净值 | Net Asset Value (NAV) | 基金资产减去负债后每份的价值 |
| 溢价率 | Premium Rate | (市价-净值)÷净值 |
| 折价率 | Discount Rate | (净值-市价)÷净值 |
| 跟踪差异 | Tracking Difference | ETF收益与指数收益的实际差额 |
| 授权参与商 | Authorized Participant (AP) | 可以在一级市场申购赎回ETF份额的大型金融机构 |
| 定投 | Dollar-Cost Averaging (DCA) | 固定时间、固定金额持续投资 |
| 资产配置 | Asset Allocation | 在不同资产类别之间分配资金 |
| 再平衡 | Rebalancing | 将投资组合比例恢复到目标配置 |
| 相关性 | Correlation | 不同资产价格之间的联动关系 |
| 超额收益 | Alpha | 基金收益减去基准收益 |
| 最大回撤 | Maximum Drawdown | 从高峰到低谷的最大跌幅 |
| QDII | Qualified Domestic Institutional Investor | 合格境内机构投资者（可投境外市场） |
| FOF | Fund of Funds | 投资于其他基金的基金 |
| 下滑曲线 | Glide Path | 养老目标基金随目标日期临近逐步降低权益比例 |

## 附录 L · 不同司法辖区需自行确认的事项

以下事项在不同国家和地区存在显著差异。本书不提供具体法律或税务建议，读者应当根据自己所在地的最新法规自行确认。

| 事项 | 说明 |
|------|------|
| 证券账户开立条件 | 不同国家/地区对非居民开户的限制不同 |
| 个人所得税 | 投资分红、基金赎回收益、海外投资收益的税率和申报要求因地区而异 |
| 资本利得税 | 部分地区有、部分地区没有；长期持有和短期交易的税率可能不同 |
| 预扣税（Withholding Tax） | 投资海外资产时，所在国可能对股息分红预先扣缴税款 |
| 外汇管制与额度 | 部分国家有外汇管制，限制个人每年购汇或向境外转移资金的上限 |
| QDII额度限制 | 中国境内的QDII基金受外汇管理局批准的额度限制 |
| ETF税务处理 | 不同注册地（如中国大陆、香港、美国、爱尔兰）的ETF对分红的税务处理差异 |
| 遗产税与继承 | 持有海外资产时，不同国家/地区对遗产税和继承程序的规定差异 |
| 投资者保护基金 | 不同地区对券商破产时客户资产的保护范围和上限不同 |
| 产品准入 | 部分ETF或基金因监管原因不向特定地区的居民销售 |
| 信息披露语言 | 海外ETF的招募说明书和报告语言可能是英文或其他外语 |

> **重要提醒：以上事项的具体规定以各地区最新法规为准，并可能随时更新。本书不构成法律、税务或移民建议。**
