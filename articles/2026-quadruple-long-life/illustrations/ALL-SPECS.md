## Git 跟踪策略

PNG、JPG、CSV 等二进制文件通过 **Git LFS** 管理：
- 仓库中仅存轻量指针文件（~130 bytes/个）
- 实际文件存储在 GitHub LFS 服务器
- clone 时按需下载，不占仓库历史体积
- 配置文件：`.gitattributes`（`*.png *.jpg *.jpeg *.csv filter=lfs`）
