# 文章风格指南 / Article Style Guide

> 中文为主 · English below
> 
> **适用范围：** 本指南约束 `articles/` 下所有**短篇 essay**（约 2,000–5,000 字，单文件 `manuscript.md`）。
> **专著/书稿项目**（如 `2026-quadruple-long-life/`）使用独立的多文件结构与约定——参见该书稿的 `agents.md`。

本指南保证所有短篇长文风格一致。动笔前请先读 `_template/`。

## 1. 语气与立场 (Voice & stance)
- 自信、克制、有思辨，不喊口号。
- 投资洞察与人生哲思结合，用数据/案例支撑观点。
- 可用第一人称，但避免情绪化宣泄。

## 2. 结构 (Structure)
- 仅一个 H1，即文章名；章节用 H2；子节用 H3。
- 开头给“钩子 + 核心论点”；结尾给“行动 / 反思”。
- 建议篇幅：中文 2000–5000 字。

## 3. 双语规则 (Bilingual policy) — 中文为主，英文混排
- 单一权威稿为 `manuscript.md`：**中文为主，英文混排于同一文档**。
- 英文以内联方式出现：专有名词 / 缩写 / 关键术语首次出现时附英文，
  如 `认知 (cognition)`、`做多 (long)`、`回撤 (drawdown)`；可用 **English** 强调。
- 默认不再另起一份完整英文翻译稿；如某篇确需独立英文版，可额外提供
  `manuscript.en.md`（可选，非默认）。
- 术语英文写法首次出现后，后文可只用中文。

## 4. 格式 (Formatting)
- 使用 Markdown；列表、引用、分隔线适度。
- 数字 / 百分比用阿拉伯数字；金额用 ¥。
- 强调用 **粗体**，少用斜体。

## 5. 引用与素材 (References & assets)
- 引用统一放入 `references.md`，正文用 [^1] 脚注或文内链接。
- 图片放入 `assets/`，用相对路径引用。
- 素材仅限本文章夹，不外链占用。

## 6. 命名 (Naming)
- 文章文件夹：`<yyyy>-<english-slug>/`。
- 文件：`manuscript.md` / `notes.md` / `references.md` / `README.md` / `README-zh_CN.md` / `assets/`。

# Article Style Guide (English)

This guide keeps every long-form essay consistent. New articles start from `_template/`.

## 1. Voice & stance
- Confident, restrained, analytical — no slogans.
- Blend investment insight with life philosophy; back claims with data/cases.
- First person allowed, but not emotional.

## 2. Structure
- Exactly one H1 (the title); sections H2; subsections H3.
- Hook + thesis up top; action / reflection at the end.
- Target length: 2,000–5,000 Chinese characters.

## 3. Bilingual policy — Chinese-primary, English inline
- Single canonical file `manuscript.md`: **Chinese-primary with English mixed inline** in one document.
- English appears inline: on first use of a proper noun / acronym / key term, append English, e.g. `认知 (cognition)`, `做多 (long)`, `回撤 (drawdown)`; **English** may be used for emphasis.
- No separate full English translation by default. If a piece truly needs a standalone English version, provide `manuscript.en.md` optionally (not default).
- After first use, later mentions may use Chinese only.

## 4. Formatting
- Markdown; use lists / quotes / rules sparingly.
- Arabic numerals for numbers / percent; ¥ for currency.
- Emphasis with **bold**; avoid italics.

## 5. References & assets
- Citations go in `references.md`; use [^1] footnotes or inline links.
- Images in `assets/`, referenced by relative path.
- Assets stay within the article folder.

## 6. Naming
- Article folder: `<yyyy>-<english-slug>/`.
- Files: `manuscript.md` / `notes.md` / `references.md` / `README.md` / `README-zh_CN.md` / `assets/`.
