# Review Output Format

The editorial review should be written as a single Markdown file saved to `EDITORIAL-REVIEW.md` in the manuscript directory.

## Structure

### 1. Header
```
# 编辑审读报告 · Editorial Review

**书稿：**《书名》
**审读日期：** YYYY-MM-DD
**审读范围：** 列出所有章节（注明哪些已完成、哪些是占位符/待写）
```

### 2. Overall Impression (总体印象)

2-3 paragraphs summarizing the manuscript's strengths and fatal flaws. Be direct. Name the core problem in the first paragraph.

### 3. Per-Chapter Reviews (逐章审读)

For every chapter, including front matter and back matter if substantive:

```
### 第X章 · 章节名称

**Overall Score:** X/10
**Decision:** Keep / Minor Revision / Major Rewrite / Rewrite from Scratch

**Problems:**
- Bullet list of specific issues with examples
- Reference page/paragraph content when useful

**Strengths:**
- Bullet list of what works

**Editorial Comments:**
2-4 paragraphs of actionable feedback. Write like an experienced editor — specific, constructive, and blunt.
```

### 4. Cross-Cutting Issues (全局问题)

Organized by theme (one section per issue):

```
### N. Issue Name

**Severity:** Critical / Major / Moderate

Description of the problem across chapters.

**Evidence:** List chapters affected and specific examples.

**Recommendation:** Concrete fix.
```

Common cross-cutting issues to check for:
- Structural repetition (same idea in N chapters)
- Template fatigue (identical chapter structure throughout)
- Data vacuum (no specific numbers anywhere)
- Missing stories/cases (all hypothetical examples)
- Section redundancy (e.g. all 茶话会 are restatements)
- Audience/positioning problems (niche targeting limiting commercial viability)

### 5. Overall Score (综合评分)

```
### 全书总分：X.X / 10

| 维度 | 得分 | 说明 |
|------|------|------|
| Book Quality | X/10 | one-line summary |
| Depth | X/10 | one-line summary |
| Narrative Flow | X/10 | one-line summary |
| Paragraph Style | X/10 | one-line summary |
| Repetition | X/10 | one-line summary |
| Timelessness | X/10 | one-line summary |
| Emotional Tone | X/10 | one-line summary |
| Extra Sections | X/10 | one-line summary |
```

### 6. Rankings (排名)

```
### 最强章节 Top 5
1. 第X章 · 名称（X/10）— one-sentence reason
...

### 最弱章节 Top 5
1. 第X章 · 名称（X/10）— one-sentence reason
...
```

### 7. Rewrite Priority (重写优先级)

```
### 必须重写的章节（按优先级排序）

1. 第X章 · 名称 — 说明原因和重写方向
2. ...
```

### 8. Final Verdict (最终判断)

```
### 如果这份稿件今天提交给[出版社名称]，能否通过编辑初审？

**答案：** Ready for publication / Needs revision / Major revision required

**原因：**

3-5 paragraphs explaining the verdict.

Then: a constructive "如果要做，怎么做" section with concrete action items numbered 1-N.
```

## Language

- Write in Chinese for Chinese manuscripts, English for English manuscripts.
- The review itself should match the manuscript's language.
- Be direct. No softening language before criticism.
- Reference comparable published books by name.
