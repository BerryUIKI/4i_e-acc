# Screen decks — `skills/screen-deck`

16:9 presentation decks built from the same Markdown as the print book. One PDF
per book part, so each part can be used as a talk on its own.

```bash
python skills/screen-deck/scripts/build_decks.py
```

| Flag | Effect |
|---|---|
| `--part A` | Build only these parts (repeatable). Keys: `FM A B C D E F G I H APX`. |
| `--html-only` | Write HTML without rendering PDFs (fast preview). |

Output: `output/decks/<key>.pdf`, HTML intermediates in `output/decks/html/`,
redrawn charts in `output/decks/charts/`. All three live under `output/`, which
is gitignored — the decks are build artifacts, never committed.

## Decks

| File | Contents |
|---|---|
| `fm00.pdf` | Front matter: opening statement, reading notice, author's note, prologue |
| `a01.pdf` – `i08.pdf` | Parts I–VIII, one deck each |
| `h09.pdf` | Epilogue |
| `apx10.pdf` | Appendices A–N as one reference deck |

Parts map to `book-task.md` by filename prefix (`A001` → part A, `E003` → part E).
Entries whose title contains 附录 route to the appendix deck instead.

## Slide grammar

| Kind | Built from |
|---|---|
| `cover` | Part opener: index number, Chinese title, English subtitle |
| `toc` | That deck's chapters, or the fourteen appendices |
| `chapter` | Each chapter or appendix heading, with its epigraph when present |
| `lead` | Each `###` section heading plus its first sentence, set large |
| `content` | One paragraph, split at sentence boundaries into 112-character slides |
| `figure` | Any Markdown image, replaced by the redrawn deck chart when one exists |
| `closing` | End of deck |

One idea per slide is the governing rule. Long paragraphs split at sentence
boundaries so nothing overflows a 960×540 page — that is why the decks are not a
mirror of the print edition.

## Charts

`deck_charts.py` redraws the book's twelve charts for projection: bold palette,
fewer ticks, larger type, and an annotated takeaway inside each figure. Charts
are regenerated by `build_decks.py`, or directly:

```bash
python skills/screen-deck/scripts/deck_charts.py
```

**Data must come from the book.** Values use the same teaching inputs as
`articles/2026-quadruple-long-life/analysis/src/`; the DCA price path is imported
from `teaching_models.py` rather than retyped so a chart cannot drift from the
manuscript. Every figure keeps its provenance line. Do not add a chart from
memory — add it to the analysis scripts first, then import it here.

## Requirements

- Python with `matplotlib` and `numpy`
- Chrome or Edge (headless rendering); the script probes the usual install paths
- Source Han fonts from `skills/pdf-toolbook/assets/fonts/`

## Editing the book

Decks rebuild from the Markdown; there is nothing to edit here when prose
changes. Only touch this folder to change slide layout, chart design, or which
content becomes a slide.
